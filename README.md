# StackSketch AI

StackSketch AI is an AI-powered project planning tool that turns software ideas into recommended tech stacks, architecture explanations, and visual system diagrams.

## Features

- Enter a project idea
- Generate a recommended tech stack
- Explain how each technology connects
- Display a simple architecture diagram
- Save or export project blueprints later

## Tech Stack

- Frontend: Next.js, TypeScript, Tailwind CSS
- Backend: FastAPI, Python
- AI Layer: OpenAI/Gemini/Claude later
- Database: PostgreSQL later
- Diagram: Mermaid.js or React Flow later
